# Failure taxonomy — settled in Phase 2, 2026-10-26

Source: `raw/corpus/defects.csv` (29 rows, eight apps, after the reclassification in `patterns/CLUSTERING.md`).
`defects.csv` columns: `app,commit,screen,pose,class,detector,evidence_png,notes`.

A class is admitted only if it appears in ≥ 2 corpus apps or in Apple's own guidance as a named hazard.
Detectors live in `Sources/DuoDetectors/Detectors/`. Static detectors run as a source scan in the skill; dynamic
detectors run on frames captured on the simulator: the pattern catalog's own records, or for any other app the
accessibility tree XCTest reads in each pose (`Sources/DuoDetectors/AccessibilitySnapshot.swift`, which states its
mapping rules and is checked against the catalog's records in all 119 captures). Tech-talk citations give the chapter's start time (`raw/apple-docs/tt-*.md`; notes keep chapter order).
Thresholds are measured: the division frame is 455.5–495.5 pt on the
folded axis of the 951 × 669 pt inner display, margins included, and active only when part-folded (`raw/metrics.json`).

Status: **admitted** (evidence meets the rule) · **named** (Apple names it, no corpus evidence yet) · **provisional**
(one app, no Apple naming) · **out of scope**.
